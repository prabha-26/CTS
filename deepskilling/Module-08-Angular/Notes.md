# Module 08 - Angular

Hands-on implemented in `cts-angular-hands-on`.

## Objective
Create a simple Angular frontend and understand the core building blocks of component-based UI development.

## What you practice
- Creating a standalone Angular application
- Configuring routing with `provideRouter`
- Binding data in templates with interpolation and `*ngFor`
- Building forms with `ngModel`
- Organizing reusable logic in services

## Key concepts
- Components, templates, and styles
- Data binding and event binding
- Routing between views
- Dependency injection with services
- Angular project structure and bootstrapping

## Hands-on flow
1. Install dependencies.
2. Start the development server.
3. Open the application in the browser and inspect the rendered UI.
4. Update the components and services to observe how Angular re-renders the view.

## Run
```bash
cd cts-angular-hands-on
npm install
npm start
```

The Angular CLI will launch the app locally, typically at `http://localhost:4200`.
