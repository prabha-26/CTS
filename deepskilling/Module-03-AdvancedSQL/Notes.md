# Module 03 - Advanced SQL Server

Completed SQL scripts:

- `AdvancedSQL.sql`: ranking and window function examples.
- `Indexes.sql`: index creation and query tuning hands-on.
- `Views.sql`: reusable views.
- `StoredProcedures.sql`: create, execute, and return data from stored procedures.
- `Functions.sql`: scalar and table-valued function examples.
- `Triggers.sql`: trigger examples.
- `Cursors.sql`: cursor examples.
- `ExceptionHandling.sql`: `TRY...CATCH` and transaction handling.

Run the scripts in SQL Server Management Studio or Azure Data Studio against a practice database.
