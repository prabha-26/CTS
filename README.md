# CTS Training Repository

This repository contains Cognizant training hands-on work split into two tracks.

## Structure

| Folder | Contents |
| --- | --- |
| `deepskilling/` | .NET FSE deepskilling modules with notes, source code, SQL scripts, and runnable project scaffolds. |
| `upskilling/` | Frontend, SQL, and C# upskilling exercises and submitted outputs. |

## Deepskilling

The deepskilling track includes Modules 01-13 with local notes, source files, SQL scripts, and project scaffolds.

See `deepskilling/README.md` for the full module completion index.

## Upskilling

The upskilling track includes:

- Module 1: HTML, CSS, Bootstrap, JavaScript, jQuery, and image assets.
- Module 2: SQL exercise output document.
- Module 3: C# ADO.NET exercises 1-30.

Generated `.NET` build output is ignored and should be recreated locally with `dotnet build` or `dotnet run`.

## Repository Hygiene

- Source files, notes, and project files are tracked.
- Generated folders such as `bin/`, `obj/`, `node_modules/`, `dist/`, and `.angular/` are ignored.
- Binary document files such as `.pdf`, `.docx`, `.xlsx`, and `.zip` are marked as binary in Git.
